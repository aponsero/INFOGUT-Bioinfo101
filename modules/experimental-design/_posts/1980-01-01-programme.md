# Experimental design

{% include module_overview.html %}

This module is a lecture rather than a hands-on tutorial: there is nothing to install and no code to run. It explains how to design in vitro colon model experiments so that the data can answer your question, before any statistical test is run.

## What you will learn

- The sources of variation in colon model experiments: donor, vessel, batch or run, and technical
- The difference between biological and technical replicates (pseudoreplication)
- The controls to include: blank, vehicle, positive and baseline
- How to deal with confounders through randomization and blocking
- Why repeated samples from one vessel are not independent
- How to calculate statistical power and sample size
- How paired, baseline-corrected designs reduce the number of vessels you need

## Prerequisites

None.
