# About this course

This website is a self-study version of the [Third INFOGUT Training School](https://aponsero.github.io/INFOGUTWG4-TrainingSchool-2026/), "Bioinformatics 101 for colon model experiments", held at IMDEA Nutrition (Madrid, Spain) on 28 to 30 September 2026. The school was organised by Working Group 4 of COST Action CA23110 (INFOGUT).

The course combines theory with hands-on practice in R, Unix/Bash, GitHub, statistical analysis, FAIR data principles and reproducible bioinformatics workflows.

## Who it is for

- PhD candidates, postdoctoral researchers and technical staff.
- People who work with in vitro colon models, or are planning to.
- No background in programming is assumed. If the command line and coding make you nervous, this course is designed for you.

## How to use this website

Each module is listed in the top menu. Inside a module, the tutorials are listed in the left sidebar, in the order in which they should be followed.

If you are new to bioinformatics, we recommend following the modules in order. If you already have some experience, you can go directly to the module you need: the overview page of each module lists its prerequisites.

## Beginner and advanced levels

This website covers the **beginner level**. More advanced tutorials will be published on a separate website, linked from the home page and from each module once available.

## What you need

A computer on which you can install software. See the [Setup]({{ site.baseurl }}/modules/about/setup/) page.
