## Computer requirements

- A laptop or desktop computer.
- The right to install software on it. If you do not have administrator rights, ask your IT department to install the software listed below.
- At least 8 GB of RAM (16 GB recommended).

Some modules need nothing installed:

| Module | What you need |

| Experimental design, Statistics, Microbiome, FAIR data, Reproducible research | A web browser |
| R and RStudio | R, RStudio and some R packages (see below) |
| Metabolomics, Part 2 | R, RStudio and the `tidyverse` package |

## Install R and RStudio

R and RStudio are **two different programs**, and you need both:

- **R** is the engine: the program that actually runs your code.
- **RStudio** is the window you work in. It sends your instructions to R and shows you what comes back.

Install **R first, then RStudio**. RStudio looks for R when it starts. After that, you only ever open RStudio.

## Check that it works

Open **RStudio** (not R). Click in the **Console** pane, at the `>` symbol, type each line and press Enter.

```r
1 + 1
```

R should answer:

```
[1] 2
```

Then:

```r
R.version.string
sessionInfo()
```

The first line prints the version of R you installed. The second prints more details about your system. If both run without an error, R and RStudio are working.

## Install the R packages

Packages are installed **once per computer**, and need an internet connection. Each tutorial page lists the packages it uses, so you only need the ones for the parts you plan to follow.

| R and RStudio module | Packages |
|---|---|
| Parts 1 to 3 | None: only what comes with R |
| Parts 4 and 5 | `dplyr` |
| Part 6 | `dplyr`, `ggplot2`, `vegan`, `phyloseq` |
| Part 7 | `phyloseq`, `mia`, `miaViz`, `ComplexHeatmap`, `scater`, `patchwork` |

To install everything at once, run these two lines in the RStudio console. The first installs packages from CRAN, the main R package repository. The second installs packages from Bioconductor, the repository for biology and omics data, which has its own installer.

```r
install.packages(c("dplyr", "ggplot2", "vegan", "patchwork", "BiocManager"))
BiocManager::install(c("phyloseq", "mia", "miaViz", "ComplexHeatmap", "scater"))
```

Part 7 needs a recent version of R and Bioconductor: the tutorial was tested with R 4.5 and Bioconductor 3.22, and some of the functions it uses do not exist in older versions (for example Bioconductor 3.20). If you install R now, you get a recent version.

The Bioconductor packages can take several minutes to install. If R asks whether to update other packages (`Update all/some/none?`), you can answer `n`.

To check that a package is installed, load it:

```r
library(dplyr)
```

No message, or only informative messages, means it worked. An error saying `there is no package called 'dplyr'` means it is not installed yet.
