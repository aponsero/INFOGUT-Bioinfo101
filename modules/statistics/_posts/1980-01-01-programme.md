# Statistics

{% include module_overview.html %}

> *"A clean design still gets ruined by the wrong test, or the right test run a few thousand times without correcting for it."*

This module is a lecture rather than a hands-on tutorial: there is no code to run. It follows on from the [Experimental design module]({{ site.baseurl }}/modules/experimental-design/programme/): once the experiment is well designed, how do you choose and report the right statistical analysis for microbiome data from colon models?

## What you will learn

- How to explore microbiome data, and why it is compositional
- Hypothesis testing fundamentals, and how to check test assumptions
- How to test differences in alpha and beta diversity
- Differential abundance and compositionality
- How to correct for multiple comparisons
- The difference between effect size and statistical significance

## Prerequisites

The [Experimental design module]({{ site.baseurl }}/modules/experimental-design/programme/), in particular biological replicates, power and sample size.
