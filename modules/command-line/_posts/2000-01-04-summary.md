# Summary

## Where you got to

At the start of this module you may never have opened a terminal. You can now:

- find your way around a filesystem and describe where things are
- create, copy, move and delete files
- describe many files at once with a wildcard
- look inside files and search them for what you need
- connect commands together and send results to a file
- write a loop, save it in a script, run it, and debug it when it breaks

**And you've probably forgotten most of the syntax already.** That's fine. Everyone does. What you keep is the part that matters: knowing these things are possible, and recognising when a problem is one the command line could solve. The table below is there for when you need the syntax again.

## All commands in one table

| Command or symbol | What it does | Part |
|---|---|---|
| `pwd` | Where am I? | 1 |
| `ls`, `ls -l`, `ls -a` | What's here (in detail, including hidden files) | 1 |
| `cd folder`, `cd ..`, `cd ~`, `cd -` | Go into a folder, up one level, home, back | 1 |
| `tree` | Draw the folder structure | 1 |
| `mkdir name` | Make a folder | 1 |
| `touch name` | Make an empty file | 1 |
| `/`, `~`, `.`, `..` | Root, home, here, up one level | 1 |
| Tab, up arrow | Complete what you're typing, bring back a command | 1 |
| `cp old new` | Copy a file | 2 |
| `mv old new` | Move or rename a file | 2 |
| `rm name` | Delete a file (no recycle bin) | 2 |
| `*`, `?`, `[12]` | Wildcards: any characters, one character, one from a set | 2 |
| `cat`, `head`, `tail` | Print a whole file, its start, its end | 2 |
| `wc -l file` | Count lines | 2 |
| `grep "word" file` | Show lines containing the word (`-i`, `-n`, `-c`, `-v`, `-r`) | 2 |
| <code>&#124;</code> | Send output into the next command | 2 |
| `>`, `>>` | Send output into a file (replace, append) | 2 |
| `command --help`, `man command` | Get help (real computers only) | 2 |
| `name="value"`, `$name` | Store something in a variable, use it | 3 |
| `for x in list; do ... ; done` | Do something to each item in a list | 3 |
| `#` | Comment: ignored by bash, read by humans | 3 |
| `>&2` | Send to the error stream | 3 |
| Exit code | 0 means finished fine, anything else means something went wrong | 3 |
