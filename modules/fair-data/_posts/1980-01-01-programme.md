# FAIR data

{% include module_overview.html %}

This module is about organising and documenting a dataset so that a stranger can use it: the data life cycle, data management plans, minimum information standards and the FAIR principles. It finishes with a hands-on exercise where you restructure and document a project folder of your own.

## What this module covers

**In this module:** the data management cycle, the FAIR principles, minimum information standards, and organising and documenting a dataset so that a stranger can use it.

**Not in this module:** code reproducibility (environments, dependencies, package versions, random seeds). This is covered in the [Reproducible research module]({{ site.baseurl }}/modules/reproducible-research/programme/).

**What you leave with:** a small dataset you have restructured yourself, with its metadata file and its README written, organised and ready to put on GitHub in the [Reproducible research module]({{ site.baseurl }}/modules/reproducible-research/programme/).

## Prerequisites

- **Part 1:** none.
- **Part 2:** a project folder to clean up. The exercise uses the folder you worked in during the [R and RStudio module]({{ site.baseurl }}/modules/r/programme/); any small project folder of your own works too.
